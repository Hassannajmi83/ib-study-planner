Subject Guide

Physics

Method marks decide your grade. The right answer with no steps can still lose marks.

Scoring-7 rule: Diagram → Formula → Substitute → Solve → Units → Sig figs → Reasonableness check.

Calculation Template (Always)

  • Write known values (with units)
  • Choose formula + define symbols
  • Substitute with brackets
  • Show steps clearly
  • Final: units + sig figs + statement

Core Skills

  • Free-body diagrams
  • Graphs: slope/area interpretation
  • Vector components
  • Uncertainty + error sources

Common Mark Traps

  • Wrong sign / direction
  • Not converting to SI
  • Skipping diagram
  • Rounding too early

How to Study (Weekly)

  • 3x/week: problem sets (mixed topics)
  • 1x/week: timed mini-test
  • Daily: formula + concept recall (10 mins)
  • Error log: list repeated mistakes

Quick Checklist

  • Did I draw a diagram?
  • Did I show substitutions?
  • Did I use correct units + sig figs?
  • Does the answer make sense?

Exam Habit That Boosts Marks

After every question: write one sentence that states what your answer means (e.g., “Therefore the acceleration is 2.1 m/s² downward.”) It makes your work clearer and helps you catch sign/direction errors.
