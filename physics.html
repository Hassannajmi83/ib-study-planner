Physics

Diagrams + method marks + clean assumptions.

← Back to Subjects

Papers

  • Paper 1: MCQ (concept traps + data booklet familiarity)
  • Paper 2: structured problems (method marks)
  • Paper 3: data/skills + option-style (depends on syllabus)
Physics marks are “visible”: show forces, show components, show steps.

High-impact study plan

  • Booklet mastery: know where the common equations live
  • Pattern practice: do 10–15 questions of the same type, then mix
  • Timed sets: train “fast setup” (diagram → equation → substitution)
  • Error log: write the rule you should’ve used (units, sign, direction, trig)

Common mark traps

  • Wrong direction/sign (vectors, acceleration, fields)
  • Using degrees vs radians incorrectly
  • Forgetting to resolve components
  • Not stating assumptions (no air resistance, point mass, etc.)
  • Final answer missing units / wrong sig figs

“Method mark” checklist

  • Diagram drawn (FBD / rays / circuits)
  • Knowns/unknowns stated
  • Equation chosen + rearranged symbolically
  • Substitution shown clearly
  • Final answer: unit + sensible magnitude
