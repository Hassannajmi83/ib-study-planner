How to use this page

If you collect 50 links you’ll use 2. The goal is a clean toolkit:

  • Max 10 links per subject (or it becomes procrastination)
  • If you save a link, write what it’s for (topic practice / notes / diagrams)
  • Weekly rule: 1 timed set + markscheme review + fix rules
  • Don’t copy notes. Turn content into practice questions
