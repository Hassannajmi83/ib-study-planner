Subject Guide

Computer Science

CS is a logic + precision + traceability subject. Marks come from correct terminology, clean algorithms, and accurate trace tables.

High score rule: Always write answers clearly enough that someone else could execute your algorithm.

Assessment Structure

Exact structure depends on SL/HL and syllabus version.

Paper 1

Core knowledge.

  • System fundamentals.
  • Data representation.
  • Short structured responses.

Paper 2

Option topic.

  • Detailed theory.
  • Applied questions.

Paper 3 (HL)

Case study.

  • Pre-released material.
  • Apply theory to context.

Best Study Method (CS)

  • Practice writing pseudocode weekly.
  • Create trace tables for algorithms.
  • Review definitions (RAM, ROM, OOP, etc.).
  • Test yourself without IDE support.
CS mistake pattern: Students rely on intuition instead of structured logic.

Algorithm Answer Template

  • State objective clearly.
  • Write step-by-step pseudocode.
  • Use indentation properly.
  • Create trace table if needed.
  • Test with sample input.
Always use clear variable names and consistent logic.

Common Mark Traps (CS)

Trap 1: Incomplete pseudocode

Include all steps — input, process, output.

Trap 2: Missing definitions

Use correct terminology precisely.

Trap 3: No trace table

Show how variables change step-by-step.

Quick Practice Checklist

  • Can I write correct pseudocode without looking?
  • Do I understand how memory/storage works?
  • Can I trace algorithms accurately?
  • Do I use precise terminology?
