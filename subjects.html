Subjects

Pick a subject. Each page should have paper structure + strategy + common mark traps.

Biology

Data skills + command terms

Use diagrams + precise wording. Avoid vague “it increases” answers.

 Chemistry

Units + mechanisms + discipline

Show method marks. Track units. Use correct sig figs.

 Physics

Method marks + diagrams

Always state assumptions. Use consistent symbols and directions.

 Math AA

Steps shown + domain checks

Don’t skip algebra. State restrictions. Check trig ranges.

 Economics

DEED structure + evaluation

Define → Explain → Example → Diagram, then evaluate clearly.

 Psychology

Study structure + research methods

Link to theory. Use studies correctly. Evaluate limitations.

 Business

Definitions + structure + real examples

Don’t waffle. Apply tools (SWOT, Ansoff, BCG) properly.

 English

Thesis clarity + literary analysis

Point → evidence → effect → author purpose. Stay tight.
