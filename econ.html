Subject Guide

Economics

Economics is a structure + diagram + evaluation subject. High marks come from using the correct framework every time.

High score rule: Define → Explain → Example → Diagram (DEED). Then evaluate with a clear judgement.

Assessment Structure

Exact structure depends on SL/HL and syllabus year.

Paper 1

Essay questions.

  • Clear definitions.
  • Fully labelled diagrams.
  • Evaluation with balanced judgement.

Paper 2

Data response.

  • Use extract evidence.
  • Integrate diagrams with explanation.
  • Explain before evaluating.

Paper 3 (HL)

Quantitative policy + calculations.

  • Show working clearly.
  • Interpret results in economic terms.
  • Link back to theory.

Best Study Method (Econ)

  • Memorize definitions precisely.
  • Draw diagrams from memory weekly.
  • Practice 10- and 15-mark essays.
  • Build evaluation templates.
Econ mistake pattern: Students explain well but forget evaluation or diagrams.

Essay Structure (10 / 15 Mark)

  • Define key terms.
  • Explain theory step-by-step.
  • Diagram fully labelled.
  • Example (real-world).
  • Evaluate with judgement (for 15-mark).
Use clear paragraphs — not bullet points — in actual exams.

Common Mark Traps (Econ)

Trap 1: Missing diagram labels

Always label axes + curves + equilibrium points.

Trap 2: No evaluation

Evaluation = depends on time frame, magnitude, stakeholders.

Trap 3: Weak examples

Use specific real-world references.

Quick Practice Checklist

  • Can I draw AD-AS from memory?
  • Can I explain inflation/unemployment clearly?
  • Do I evaluate with judgement?
  • Do I use DEED consistently?
