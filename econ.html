Economics

SL vs HL + diagrams + evaluation structure.

← Back to Subjects

Papers

  • Paper 1: extended response (essays + evaluation)
  • Paper 2: data response (short + structured)
  • HL only Paper 3: policy + calculations / deeper analysis
Econ = DEED: Define → Explain → Example → Diagram (then evaluate).

High-impact study plan

  • Diagram bank: master a small set of core diagrams perfectly
  • Evaluation templates: short-run vs long-run, stakeholders, assumptions
  • Data practice: read quickly, quote numbers, link to theory
  • Weekly: 1 timed paragraph plan + 1 timed full response

Common mark traps

  • Diagram not labelled (axes, curves, shifts, equilibrium)
  • No chain of reasoning (just “it increases”)
  • Evaluation is generic (not linked to your scenario)
  • Forgetting welfare impacts / deadweight loss
  • Not using key terms (PED, inflationary gap, terms of trade)

Evaluation quick checklist

  • State assumptions
  • Short-run vs long-run
  • Stakeholders (consumers, firms, government)
  • Unintended consequences
  • Clear judgement (best option + why)
