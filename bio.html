Biology

Paper structure + command terms + data skills + common traps.

← Back to Subjects

Papers

  • Paper 1: MCQ (concept + careful reading)
  • Paper 2: short + extended responses (keywords matter)
  • Paper 3: data response + practical/skills focus (varies by syllabus)
Bio is a “keyword sport”: the markscheme is picky — learn the exact phrasing.

High-impact study plan

  • Active recall: questions first, notes second (don’t rewrite textbooks)
  • Data drills: graphs, error bars, trends, controls, variables
  • Markscheme training: after each set, copy the exact accepted wording once
  • Weekly: timed Paper 2 section + review wrong answers
Make a “command term” cheat sheet (describe vs explain vs evaluate).

Common mark traps

  • Answer is correct but missing a required keyword
  • Confusing correlation vs causation in data questions
  • Not naming the variable / not stating direction of change
  • Forgetting units / axes labels / gradient meaning
  • Not linking back to the question wording (“therefore…”)

Paper 2 “easy marks” checklist

  • Use key terms (enzyme active site, diffusion gradient, allele frequency, etc.)
  • Answer in the same unit the question uses
  • For processes: steps in order + name the structure
  • For evaluations: 1 pro + 1 con + conclusion
