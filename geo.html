Subject Guide

Geography

Geography is case studies + data interpretation + evaluation. Marks come from using real examples + linking to concepts.

High score rule: Every big answer needs: concept → evidence/case → explanation → evaluation.

Assessment (What to Expect)

Data Response

  • Describe patterns/trends first.
  • Use numbers when possible (comparisons).
  • Explain using geographic concepts.

Extended Response / Essays

  • Use a clear thesis and paragraph structure.
  • Include 2+ case studies per question.
  • Evaluate (pros/cons, limits, judgement).

Best Study Method (Geo)

  • Case study bank: 10–15 strong cases with stats.
  • Weekly: 1 data-response timed set.
  • Flashcards: key terms + processes (urbanization, migration, hazards).
  • Essay plans: practice outlining answers fast.

Common Mark Traps

  • No case study detail (names, places, numbers).
  • Describing without explaining why it happens.
  • No evaluation / judgement.
  • Not linking back to the question wording.

Quick Checklist

  • Do I have case studies with 2–3 stats each?
  • Can I explain a graph properly (trend + evidence + reason)?
  • Can I write an evaluation paragraph with a judgement?
