Subject Guide

Geography

Geography is a case study + data + evaluation subject. High marks come from linking theory to real-world examples.

High score rule: Every long answer needs a named case study.

Assessment Structure

Exact structure varies by SL/HL and syllabus version.

Paper 1

Core themes.

  • Data interpretation.
  • Structured short responses.
  • Use geographic terminology.

Paper 2

Optional themes.

  • Case study application.
  • Balanced evaluation.

Fieldwork / IA

Geographic investigation.

  • Clear research question.
  • Methodology + data collection.
  • Evaluation + conclusion.

Best Study Method (Geo)

  • Memorize 2–3 case studies per theme.
  • Practice interpreting graphs/maps.
  • Review key vocabulary weekly.
  • Write timed 10- and 15-mark responses.
Geo mistake pattern: Writing theory without linking to a named place.

Answer Structure Template

  • Define key concept.
  • Explain process clearly.
  • Apply named case study.
  • Evaluate impacts + sustainability.
  • Conclude with judgement.
Use specific data (percentages, locations, years) in examples.

Common Mark Traps (Geo)

Trap 1: No case study

Always reference a named location.

Trap 2: Weak evaluation

Discuss short vs long-term impacts.

Trap 3: Ignoring data

Use graph/table evidence in answers.

Quick Practice Checklist

  • Can I name case studies clearly?
  • Do I integrate data in my answers?
  • Do I evaluate sustainability?
  • Can I structure essays clearly?
