Subject Guide

Psychology

Theory + Study + Evaluation. You’re graded on how well you link research to the question.

Scoring-7 rule: Define → Explain theory → Study support → Evaluate → Link back.

ERQ / SAQ Structure

SAQ (Short Answer)

  • Define key term
  • Explain concept/theory
  • One study + link

ERQ (Essay)

  • Intro with thesis
  • 2+ studies
  • Evaluation throughout + final judgement

Study Summary Template

  • Aim: what was tested?
  • Method: design, participants, procedure
  • Results: what happened?
  • Conclusion: what it supports
  • Link: connect to the theory
Tip: Don’t memorize paragraphs. Memorize the template + key facts.

Evaluation Menu (Pick 2–3)

  • Reliability / replication
  • Validity (ecological, internal)
  • Ethics
  • Sampling bias
  • Demand characteristics
  • Reductionism / determinism

How to Study (Weekly)

  • 2x/week: SAQs (timed)
  • 1x/week: ERQ plan + 1 full paragraph
  • Daily: study flashcards (aim/method/results)
  • Error log: missing link / weak evaluation

Common Mark Traps

  • No explicit link to the question
  • Study described but not explained
  • Evaluation is generic
  • Only 1 study in ERQ

Quick Checklist

  • Did I define key terms?
  • Did I use a study correctly (aim/method/results)?
  • Did I evaluate and make a judgement?
  • Did I link back to the question wording?
