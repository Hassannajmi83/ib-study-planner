Subject Guide

Business Management

Structure + application. Marks come from using tools (SWOT, Ansoff, STP) correctly and applying to the case.

Scoring-7 rule: Point → Business tool → Apply to case → Evaluate → Recommendation.

Common Paper Skills

Definitions

  • Precise terminology (revenue vs profit)
  • Explain in business language

Case Application

  • Use names, numbers, context
  • Don’t write generic answers

Evaluation

  • Pros/cons + constraints
  • End with recommendation

Tools You Should Know

  • SWOT + STEEPLE
  • Ansoff Matrix
  • Porter’s Generic Strategies
  • 4Ps (Marketing Mix)
  • Decision Tree / Break-even
  • Budgets + Cash flow basics

Quantitative Marks (Easy Wins)

  • Gross profit / profit margin
  • Contribution + break-even
  • Sales forecasting basics
  • Cash flow interpretation
Rule: Show formula → substitute → units → interpretation.

Best Study Method (Weekly)

  • 2x/week: timed case questions
  • 1x/week: one “tool” revision sheet
  • Daily: definitions (10 mins)
  • Error log: generic answers, missing evaluation

Common Mark Traps

  • Not applying to the case
  • Forgetting recommendation
  • Using the wrong tool
  • No numbers/quant when available

Quick Checklist

  • Did I use a business tool?
  • Did I apply it to the case facts?
  • Did I evaluate constraints?
  • Did I finish with a recommendation?
